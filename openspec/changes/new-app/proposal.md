## Why

разверни новый react проект. Цель - обучение татрскому языку по карточкам. mobile first. База данных - это cards.ts, но понадобится еще перевоод фраз. Я хочу задеплоить на vercel
  и сделать как pwa. Изменения для пользователя сохранять в localstorage. Можно создавать группы и по группам учить карточки. Пользователь может скрывать карточки и добавлять новые.
  Взаимодействие с карточкой по свайпу. Используй best practice по бизнес логине для такого приложения

## Capabilities

### New Capabilities

- `card-catalog`: Просмотр встроенных слов и фраз с переводами, добавление пользовательских карточек и скрытие встроенных карточек.
- `card-groups`: Создание и управление группами карточек для целевого обучения.
- `study-sessions`: Обучение карточкам выбранной группы с раскрытием перевода, свайп-оценкой и сохранением прогресса.
- `local-persistence`: Локальное хранение пользовательских данных и прогресса с безопасным восстановлением при запуске.
- `progressive-web-app`: Mobile-first интерфейс, установка PWA, офлайн-запуск и статический деплой на Vercel.

Нет.
