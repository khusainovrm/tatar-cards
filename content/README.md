# Татарский: стартовые темы A1

20 тем по 50 фраз: 1 000 карточек, в том числе 42 существовавшие фразы с прежними ID. 14 прежних слов доступны в общем каталоге, но не входят в тематические группы. `a1.ts` содержит 958 новых пар «татарский | русский», `course.ts` связывает их с прежними карточками. Идентификаторы новых карточек зависят от позиции внутри темы: при дальнейшей редактуре не переставляйте строки, чтобы сохранить прогресс.

Фразы составлены для начальной бытовой практики: короткие вопросы, ответы, просьбы, настоящее время и распространённые формы прошедшего/будущего. A1 — целевой уровень материала, не сертификация. Это авторский набор; полная редакторская проверка преподавателем татарского не проводилась. Русские переводы с «он» или мужской формой прошедшего времени могут соответствовать также «она»: татарский не различает грамматический род.

Справочные ресурсы для последующей языковой редакции:

- [Электронный фонд словарей ИЯЛИ](https://suzlek.antat.ru/).
- [Русско-татарско-англо-турецкий тематический словарь ИЯЛИ](https://suzlek.antat.ru/about/aboutRTATtemE.html).

`npm run validate:cards` проверяет число тем, по 50 фраз в каждой, существование ссылок, отсутствие слов и повторных ID/текстов внутри курса, включение всех прежних фраз. Проверка структуры не проверяет правильность перевода.

Новый профиль получает группы сразу. При загрузке старого профиля группы добавляются без замены пользовательских данных; `starterContentVersion` сохраняется при следующем сохранении состояния. После этого удалённые и изменённые группы не восстанавливаются автоматически. Сброс локальных данных возвращает исходный курс. Скрытые пользователем карточки остаются скрытыми, поэтому в таком профиле видимых фраз может быть меньше 50.
